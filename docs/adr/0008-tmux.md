# 0008. tmux configuration

Status: Accepted, 2026-11-20

## Context

`tmux/.tmux.conf` is the full config on macOS and Debian. `omarchy/tmux/tmux.conf` is a personal layer that Omarchy's own `~/.config/tmux/tmux.conf` sources at its end.

## Decision

### Shared

- `history-limit` is 200000, overriding tmux-sensible's 50000. 1M was overkill and made resurrect saves larger.
- `allow-passthrough` is on, so Yazi and kitty graphics escape sequences reach the terminal.
- Windows and panes are numbered from 1. Windows renumber when one closes. Closing a session does not exit tmux (`detach-on-destroy off`). The status bar sits at the top, as on macOS.
- resurrect and continuum load *after* catppuccin. Otherwise the theme overwrites the `status-right` interpolation that continuum uses to trigger periodic saves. continuum appends its hook after the plugins load, so the status format leaves room for it. Saves run every 30 minutes, the last one is restored on start, and nvim sessions are restored too.
- tmux-thumbs copies with `pbcopy` only on macOS. Elsewhere it hands the match to tmux, which also forwards it to the terminal clipboard (`set-clipboard on`, OSC 52). Its first use compiles it with cargo.
- The session switcher calls tmux-fzf's session switch directly, because sessionx does not work with Ghostty.
- Key bindings come before TPM initialisation, and TPM's `run` stays the last line.
- `Tab` selects the last window, because `prefix l` is taken by `select-pane -R`. Splits and new windows keep the current path. Killing a session asks for confirmation.

### Omarchy layer

- Omarchy's config stays in place: prefix C-Space, Alt bindings, a status bar that follows the theme, `?` help and `q` reload. The layer changes no theme or status bar settings. Edit it with `prefix e`.
- The TPM plugin path is set explicitly, to TPM's own default for an XDG config, so the CLI installer finds it without waiting for the asynchronous `run`.
- continuum hooks its save into `status-right`, which Omarchy's config has already set by the time this file loads.
- Pane navigation and resizing replace Omarchy's `prefix h` (split) and `prefix k` (kill-window). Split with `v`, `|` or `-`, and kill a window with `prefix &`. `K` asks before killing a session, while Omarchy's version kills without asking.

## Consequences

Plugin order matters. Keep the resurrect and continuum lines after the theme in both files.
